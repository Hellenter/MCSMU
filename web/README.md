# MC Server Manager Web

Веб-версия менеджера серверов Minecraft: та же логика, что у десктоп-версии на Rust (`rust/`),
но управление идёт через браузер, с регистрацией и входом. Каждый пользователь видит только свои серверы.

## Как это устроено

`MCServerManagerWeb.exe` запускается на компьютере, где лежат серверы. Он запускает и останавливает
серверы, читает их консоль, делает бэкапы и отдаёт страницу панели:

- на этом ПК: http://localhost:8080
- в домашней сети: http://IP-компьютера:8080
- из интернета: https://ваш-домен (см. «Доступ через домен»)

Данные панели (пользователи, их серверы) хранятся в `%APPDATA%\MCServerManager\web.json`.
Настройки десктоп-версии не меняются; её серверы можно перенести в панель кнопкой в «Администрировании».

## Возможности

- регистрация и вход; первый зарегистрированный становится администратором, остальные ждут его одобрения
- запуск, остановка, перезапуск серверов; если порт занят другим вашим сервером, панель предложит его остановить
- консоль в реальном времени с историей команд
- статистика: CPU, RAM, игроки, версия, пинг, графики за 5 минут; действия с игроками (кик, бан, OP, режим игры)
- операторы, белый список, баны игроков и IP (командами, если сервер запущен, или прямо в файлы)
- редактор server.properties с подсказками
- бэкапы мира с выбором папки, ротацией и автобэкапом; скачивание бэкапа в браузер, восстановление,
  копирование мира между серверами, импорт мира из папки
- моды и плагины: включение и выключение (`.jar.disabled`, как в Prism Launcher), загрузка `.jar` из браузера, удаление
- свой SSH-туннель для серверов у каждого пользователя

## Безопасность

Любой пользователь панели может запускать программы на этом компьютере (Java, ssh), поэтому:

- одобряйте только тех, кому доверяете;
- в «Администрировании» можно ограничить папки, где обычные пользователи держат серверы;
- обычный пользователь может выбрать только Java, найденную на компьютере; свой путь к Java указывает только администратор;
- пароли хранятся в виде хешей Argon2, сессия живёт 30 дней в cookie HttpOnly/SameSite=Strict.

## Доступ через домен

1. Создайте A-запись домена (например `mc.ex1.ru`) на IP внешнего сервера.
2. На внешнем сервере от root: `sudo bash setup-nginx.sh mc.ex1.ru 8080 you@mail.ru`
   (ставит nginx и бесплатный сертификат Let's Encrypt).
3. На ПК один раз настройте вход по ключу (туннель работает без окна, пароль ввести некуда):
   ```
   ssh-keygen -t ed25519
   type %USERPROFILE%\.ssh\id_ed25519.pub | ssh minecraft@ex1.ru "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
   ```
4. В панели: «Администрирование» → «Туннель панели» → команда
   `ssh -R 127.0.0.1:8080:127.0.0.1:8080 minecraft@ex1.ru` → «Открыть» (и «Автозапуск», чтобы открывался сам).

Туннель привязан к `127.0.0.1` на внешнем сервере, так что снаружи панель доступна только через nginx и HTTPS.

## Параметры запуска

```
MCServerManagerWeb.exe [--port 8080] [--host 0.0.0.0] [--data-dir ПАПКА] [--no-browser]
```

`--host 127.0.0.1` закрывает доступ из домашней сети: останутся только этот ПК и домен.

## Сборка

```
cd web
cargo build --release
```

Файлы интерфейса (`static/`) встраиваются в exe. Логика серверов в `src/core/` скопирована из `rust/src`.
