# MC Server Manager

> **Версия 2 написана на Rust** (папка `rust/`, интерфейс на egui): один `MCServerManager.exe` без зависимостей,
> быстрый запуск, тёмная тема, живые графики, редактирование server.properties прямо в таблице.
> Готовый exe собирается в GitHub Actions (вкладка Actions → артефакт **MCServerManager**).
> Собрать самому: установить Rust с https://rustup.rs и выполнить `cargo build --release` в папке `rust`.
> Настройки общие с Python-версией (`%APPDATA%\MCServerManager\config.json`), список серверов переносится сам.
> Python-версия (файлы в корне) оставлена как запасная.

Программа для Windows (работает и на Linux/macOS) для управления несколькими серверами Minecraft
разных версий из одного окна.

## Возможности

- **Список серверов**: у каждого своя папка, jar (или аргументы для Forge 1.17+), своя Java и память.
  Запускается один сервер за раз; при старте другого программа предложит остановить текущий.
- **Запуск / остановка / перезапуск / принудительное завершение** кнопками. Остановка корректная:
  команда `stop`, а если сервер завис, через заданное время процесс убивается.
- **Консоль** с подсветкой, историей команд (↑/↓) и быстрыми кнопками.
- **Доступ из интернета** одной кнопкой: SSH-туннель `ssh -R 25565:localhost:25565 minecraft@ex1.ru`
  (команду можно поменять в «Настройках»), автопереподключение при обрыве, автозапуск вместе с сервером.
- **Статистика**: статус, аптайм, онлайн, версия, MOTD, пинг, CPU и RAM процесса, графики за 5 минут,
  список игроков онлайн с действиями (кик, бан, OP, сообщение, режим игры, в белый список).
- **Операторы, белый список, баны игроков и IP**: просмотр, добавление, удаление. Если сервер запущен,
  изменения отправляются командами, если выключен, пишутся прямо в json-файлы (UUID берётся у Mojang,
  для пиратских серверов с `online-mode=false` вычисляется офлайн-UUID).
- **server.properties**: таблица с русскими описаниями, выпадающие списки для true/false, сложности и режима.
- **Мир и бэкапы**: бэкап в zip одной кнопкой (на работающем сервере делается `save-off` / `save-all flush` /
  `save-on`, так что архив целый), автобэкап по таймеру и после остановки, хранение последних N архивов,
  восстановление (перед ним автоматически сохраняется текущий мир), экспорт мира в zip, копирование мира
  между серверами, импорт мира из одиночной игры (`.minecraft/saves`), смена `level-name`.

- **Моды и плагины**: список из папок `mods`/`plugins` с названием и версией из jar (Fabric, Quilt, Forge,
  NeoForge, плагины Bukkit/Paper), включение/выключение галочкой (переименование в `.jar.disabled`, как в
  Prism Launcher), добавление и удаление.

## Запуск

1. Установите Python 3.10+ с https://www.python.org/downloads/ (при установке отметьте «Add python.exe to PATH»).
2. Распакуйте архив в любую папку и запустите **run.bat**. При первом запуске он сам установит модуль `psutil`.
3. Нажмите «Добавить», выберите папку сервера; jar и способ запуска определяются автоматически.
   Для каждого сервера укажите подходящую Java (кнопка «Найти» ищет установленные):
   MC 1.20.5+ → Java 21, 1.18–1.20.4 → Java 17, 1.17 → Java 16, 1.16 и старше → Java 8.

### Собрать один .exe

Запустите **build_exe.bat**: появится `dist\MCServerManager.exe`, который работает без установленного Python.
Если положить проект в репозиторий GitHub, exe соберётся автоматически (`.github/workflows/build.yml`,
вкладка Actions → артефакт MCServerManager).

## Туннель без ввода пароля

Если `ssh` при подключении спрашивает пароль, оставьте включённой галочку «Открывать туннель в отдельном
окне»: появится окно консоли, где можно ввести пароль. Чтобы пароль не спрашивался вообще, один раз:

```
ssh-keygen -t ed25519
type %USERPROFILE%\.ssh\id_ed25519.pub | ssh minecraft@ex1.ru "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

После этого можно снять галочку: туннель будет работать в фоне, а его журнал виден во вкладке «Настройки».

## Где хранятся данные

Настройки: `%APPDATA%\MCServerManager\config.json`. Бэкапы: по умолчанию `<папка сервера>\backups`
(можно указать другую папку в настройках сервера). Файлы серверов программа не трогает, кроме тех,
что вы меняете через интерфейс.
